# Triage Label Vocabulary

| Kanonik rol | Etiket string'i |
|---|---|
| needs-triage | `needs-triage` |
| needs-info | `needs-info` |
| ready-for-agent | `ready-for-agent` |
| ready-for-human | `ready-for-human` |
| wontfix | `wontfix` |

## Kapsam notu

Bu repo GitHub Issues kullanmadığı için (bkz. `issue-tracker.md`) bu etiketler pratikte yalnızca **dışarıdan** (repo'nun kendi planlama akışı dışından) gelen bir GitHub issue/PR ortaya çıkarsa devreye girer. Projenin kendi iç Adım/Faz takibi `PLAN.md`'nin checkbox formatını kullanır ve bu etiket sistemine tabi değildir.
